# GitLab CE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitLab CE at `https://gitlab.silkepilon.dev` (HTTPS git only) plus an in-cluster GitLab Runner.

**Architecture:** Omnibus `gitlab/gitlab-ce` image as a single-pod Kustomize base in `apps/gitlab`, synced by a plain Argo CD Application. Runner is the upstream `gitlab-runner` Helm chart as its own Argo CD Application, Kubernetes executor, talking to GitLab over the in-cluster Service.

**Tech Stack:** k3s, Argo CD, Kustomize, Helm, Longhorn, Traefik, Cloudflare Tunnel.

## Global Constraints

- Image `gitlab/gitlab-ce:19.5.1-ce.0`; chart `gitlab-runner` `0.94.0` from `https://charts.gitlab.io`.
- Hostname `gitlab.silkepilon.dev`; no SSH anywhere; registry, Pages, KAS, bundled Prometheus off.
- No secret values in git. Secrets: `gitlab-secret` (`GITLAB_ROOT_PASSWORD`), `gitlab-runner-secret` (`runner-token`, `runner-registration-token`).
- GitLab pod and CI job pods default to `kubernetes.io/arch: amd64`.
- Storage: Longhorn, `gitlab-config` 1Gi, `gitlab-data` 30Gi.
- Follow repo conventions: header comments in `kustomization.yaml`, `revisionHistoryLimit: 2` patch, `app.kubernetes.io/part-of: homelab` label.
